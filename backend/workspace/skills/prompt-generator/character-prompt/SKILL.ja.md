# キャラクター最終プロンプト（キャラクター設定シート：正面顔クローズアップ＋表情・衣装分解＋三面図）

横長のキャラクター設定参照シートを1枚生成する。単独の人物写真にしない。外見のアンカーとして、左側の正面顔クローズアップと、右側に正面・90度側面・背面の3枚の等高全身ビューを必ず残す。拡張モジュールは中央と下部に整理し、三面図を圧迫したり削除したりしない。

## レイアウトと内容モジュール

可能な限り、明快な横長アーカイブ形式を使う：

- **左側：メイン肖像／正面顔クローズアップ**——頭部と肩部の正面アップ。顔立ち、髪型、肌質を明瞭にし、顔の識別性のアンカーとする
- **中央：6種類の表情**——平静、微笑み、怒り、驚き、悲しみ、集中。6つとも同じ顔で、変えるのは表情と雰囲気だけにする
- **中央または下部：衣装と小道具の分解**——衣服、髪飾り、アクセサリー、キャラクターを象徴する小道具の部分ディテールを示す。メインキャラクターと三面図に一致させ、未記載の物を追加しない
- **右側：正面・90度側面・背面の三面図**——同一キャラクターの等高な全身ビュー3枚を並べ、頭頂と足裏を揃え、衣装の前後構造を確認できるようにする
- **下部：配色帯**——キャラクターの実際の髪色、肌色、衣装、アクセサリーから調和する5色を抽出し、無関係な装飾色を使わない

画面のスペースが足りない場合は、人物の事実、顔の識別性、髪型、衣装の一貫性、完全な三面図を優先し、その後に表情と分解モジュールの情報密度を下げる。正面顔クローズアップや三面図を削除しない。

## 出力構造（セッションの言語で、1段落の連続した記述にする）

```
横長のキャラクター設定参照シート。左側に正面顔のメイン肖像、中央に6種類の表情と衣装・小道具のディテール分解、右側に正面・90度側面・背面の等高な全身ビュー3枚を並べ、下部にキャラクターの実際の外見から抽出した5色の配色帯を配置する；
すべてのモジュールは同一キャラクター。3枚の全身ビューは全身を画面に収め、中立的なA字の立ち姿、等高で頭頂と足裏を揃える；
[年齢感＋性別感＋体格]、[顔立ちの特徴]、[髪型]、[服装＋アクセサリー＋象徴的な小道具]；
正面顔、6種類の表情、衣装・小道具分解、3枚の全身ビューの顔・髪型・服装・小道具は完全に一致する；
純白の背景、柔らかく均一な光線、映画の質感
```

## 記述順のルール

**最も識別しやすい特徴を前に置き**、テンプレート例で人物の事実を置き換えず、`appearance` と `styling` の各要素を次の順序で漏れなく記述する：

1. 識別のアンカー：年齢感、性別感、体格（身長、体つき、姿勢の癖）
2. 顔立ち：輪郭、目、鼻、口、その他の顕著な特徴（傷跡、ほくろ、眼鏡など）——正面顔クローズアップは特にこの描写に依存する
3. 髪型：色、長さ、スタイル
4. 服装：デザイン、色、素材、状態、正面と背面で確認できる構造の細部
5. アクセサリーと小道具：人物の説明に登場する識別性のある物だけを書き、詰め込んだり新規に創作したりしない
6. 外見に現れる雰囲気と表情：性格を目線、表情、立ち姿、身体状態などの見える描写に変換する（例：「憔悴」→「疲れた目線、わずかに落ちた肩」）。抽象的な性格語を並べない

元の人物説明を最優先する。年齢、性別、体格、顔立ち、髪型、服装、アクセサリー、小道具を変更しない。記載のない細部は中立的かつ簡潔にし、強い識別性を持つ設定を勝手に追加しない。

## 構図と一貫性

- 左側の正面顔クローズアップ：カメラに正面を向き、中立的な表情、頭頂から肩まで完全に画面に収める
- 中央の6種類の表情：平静、微笑み、怒り、驚き、悲しみ、集中。顔の比率、輪郭、髪型、服装は変えず、表情と雰囲気だけを変える
- 右側の3枚の全身ビュー：同一キャラクターの正面、90度側面、背面。**等高で並べ、間隔を均等**にし、頭頂と足裏を同じ水平線上に置く
- クローズアップ、表情、衣装・小道具分解、3枚の全身ビューは同じ顔、同じ髪型、同じ服装、同じ小道具でなければならない——「すべてのモジュールの顔・髪型・服装・小道具は完全に一致」と明記する
- 三面図は中立的なA字の立ち姿と自然な表情にし、後続の画像や動画の参照アンカーとして再利用しやすくする
- 衣装と小道具の分解は現在のキャラクターのデザインだけを説明し、別の衣装、追加アクセサリー、別人を作らない
- 配色帯はキャラクターの実際の外見から取り、調和する5色に固定する。ランダムな装飾色を使わない
- 柔らかく均一なスタジオ光。劇的な光影は使わず、さまざまなシーンで使える参照シートにする
- 出力はセッションの言語指令で指定されたターゲット言語を使い、無関係な語彙を混ぜない

## 禁止事項

- 動的なポーズ、誇張された表情、三面図で手に持った小道具、他人との共演、追加の人物
- 身体の裁切（全身ビューは頭頂から足裏まで完全に画面に収め、クローズアップは頭部と肩部を完全に収める）
- 指示なしに人物の事実、顔の輪郭、髪型、服装、小道具、配色の出所を変更すること
- デフォルトでは文字、タイトル、ラベル、数字、透かし、署名、SNSアカウント表示を入れない。ユーザーが明示的に求めた場合だけレイアウト文字を生成する
- プレイヤーアイコン、再生ボタン、動画プログレスバー、字幕レイヤー、余計な枠、UI要素
- 強い影、カラーの背景光、背景小道具、ランダムな装飾、キャラクターと無関係な色ブロック

## 保存

`save_character_final_prompt` を呼び出す：prompt パラメータにスタイル語を含めない。**プロジェクトのビジュアルスタイルはツールが最終プロンプトの先頭へ自動注入する**。モジュール一覧や分析だけでなく、1つの連続した最終プロンプトを保存する。
