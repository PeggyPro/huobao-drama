# 角色最终提示词（角色档案：正脸特写 + 表情/服饰拆解 + 三视图）

生成的是一张横向角色设定参考图（character reference sheet），不是单张人物写真。基础身份锚点必须保留：左侧正脸特写，右侧并列展示正面、90 度侧面、背面三张等高全身视图。扩展模块按档案式版式分配在中部和底部，不得挤压或删除三视图。

## 版式与内容模块

优先采用清晰的横向档案版式：

- **左侧：主肖像/正脸特写**——头部与肩部正面近景，五官、发型和肤质清晰可见，作为脸部辨识度的锚点
- **中部：6 种表情**——平静、微笑、愤怒、惊讶、悲伤、专注；六个表情必须是同一张脸，只改变表情和神态
- **中部或下方：服饰与道具拆解**——展示服装、发饰、配件和角色标志性道具的局部细节，设计必须与主角色和三视图一致，不新增未描述的物品
- **右侧：正面、90 度侧面、背面三视图**——同一角色的三个等高全身视图并排，头顶与脚底对齐，完整展示服装前后结构
- **底部：配色条**——从角色实际发色、肤色、服装和配饰中提取 5 个协调色块，不使用与角色无关的装饰色

如果画面空间不足，优先保证人物事实、脸部身份、发型、服装一致性和三视图完整，再压缩表情与拆解模块的信息密度；不得删除正脸特写或三视图。

## 输出结构（按此顺序组装单段连贯描述，语言跟随会话语言指令）

```
横向角色设定参考档案，左侧为正脸主肖像，中部为六种表情与服饰/道具细节拆解，右侧并列展示正面、90 度侧面、背面三张等高全身视图，底部为从角色实际外观提取的五色色板；
所有模块都是同一角色，三张全身视图全身入镜，中性 A 字站姿，等高并排，头顶与脚底对齐；
[年龄感 + 性别感 + 体态]，[五官特征]，[发型]，[服装 + 配饰 + 标志性道具]；
正脸特写、六种表情、服饰道具拆解和三个全身视图的脸、发型、服装与道具完全一致；
纯白背景，柔和均匀的光线，电影质感
```

## 描述顺序规则

把**最有辨识度的特征放在前面**，按此顺序落地 `appearance`（样貌）与 `styling`（妆造）的每个关键元素，不遗漏，也不要用模板范例替换人物事实：

1. 身份锚点：年龄感、性别感、体态（高矮胖瘦、姿态习惯）
2. 五官：脸型、眼睛、鼻口和其他显著特征（疤、痣、眼镜等）——正脸特写尤其依赖这部分描写
3. 发型：颜色、长度、样式
4. 服装：款式、颜色、材质、状态，以及前后视图都能验证的结构细节
5. 配饰与道具：只写有辨识度且人物描述中出现的物品，不堆砌，不擅自增加
6. 外在气质与神态：把性格特点转化为可见的眼神、表情、站姿和身体状态（如“憔悴”→“眼神疲惫、肩膀微垮”），不要直接堆放抽象性格词

人物原始描述是最高优先级。不得擅自改变年龄、性别、体态、五官、发型、服装、配饰或道具；如果描述没有提供某项细节，保持中性简洁，不凭空添加强辨识度设定。

## 构图与一致性

- 左侧正脸特写：正面朝向镜头，中性表情，头顶到肩膀完整入镜
- 中部六种表情：平静、微笑、愤怒、惊讶、悲伤、专注；五官比例、脸型、发型和服装不变，只改变表情与神态
- 右侧三张全身视图：同一角色的正面、90 度侧面、背面，**等高并排、间距均匀**，头顶与脚底在同一水平线上
- 特写、表情、服饰道具拆解与三张全身视图必须是同一张脸、同一发型、同一套服装和同一组道具——明确写出“所有模块的脸、发型、服装与道具完全一致”
- 三视图使用中性 A 字站姿和自然表情，不摆动态姿势，方便作为后续图片和视频的参考锚点
- 服饰与道具拆解只能解释当前角色已有设计，不能生成第二套服装、额外配件或其他人物
- 配色条必须取自角色实际外观，固定为 5 个协调色块，不用随机装饰色
- 柔和均匀的棚拍光，不要戏剧性光影；参考图需要在各种场景下都能复用
- 输出使用会话语言指令指定的目标语言；当会话语言为中文时必须纯中文输出，不要混入无关词汇

## 禁止事项

- 动态姿势、夸张表情、三视图手持道具、与他人同框或新增人物
- 裁切身体（全身视图必须 full body，头顶到脚底完整入镜；特写必须头部肩部完整入镜）
- 擅自改变人物事实、脸型、发型、服装、道具或配色来源
- 默认不要文字、标题、标签、数字、水印、签名、社交账号标记；除非用户明确要求，不能生成任何排版文字
- 播放器图标、播放按钮、视频进度条、字幕叠层、多余边框和界面元素
- 重阴影、彩色背景光、背景道具、随机装饰物和与角色无关的色块
