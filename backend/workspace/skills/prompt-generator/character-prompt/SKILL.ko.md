# 캐릭터 최종 프롬프트(캐릭터 설정 시트: 정면 얼굴 클로즈업 + 표정/의상 분해 + 삼면도)

가로형 캐릭터 설정 참조 시트 한 장을 생성합니다. 단일 인물 사진으로 만들지 마세요. 외형 앵커로서 왼쪽의 정면 얼굴 클로즈업과 오른쪽의 정면·90도 측면·후면 같은 키 전신 뷰 3장을 반드시 유지합니다. 확장 모듈은 시트의 중앙과 하단에 정리하고 삼면도를 밀어내거나 삭제하지 마세요.

## 레이아웃과 콘텐츠 모듈

가능하면 명확한 가로형 아카이브 레이아웃을 사용합니다.

- **왼쪽: 메인 초상/정면 얼굴 클로즈업** — 머리와 어깨의 정면 근경. 이목구비, 헤어스타일, 피부 질감이 선명해야 하며 얼굴 식별도의 앵커로 사용합니다
- **중앙: 6가지 표정** — 평온, 미소, 분노, 놀람, 슬픔, 집중. 여섯 표정 모두 같은 얼굴이며 표정과 분위기만 바꿉니다
- **중앙 또는 하단: 의상과 소품 분해** — 의상, 머리 장식, 액세서리, 캐릭터를 상징하는 소품의 부분 디테일을 보여줍니다. 메인 캐릭터와 삼면도의 디자인을 일치시키고 설명에 없는 물건은 추가하지 않습니다
- **오른쪽: 정면·90도 측면·후면 삼면도** — 같은 캐릭터의 같은 키 전신 뷰 3장을 나란히 배치하고 머리 꼭대기와 발바닥을 정렬하며 의상의 앞·뒤 구조가 보이게 합니다
- **하단: 색상 팔레트 띠** — 캐릭터의 실제 머리카락, 피부, 의상, 액세서리에서 조화로운 5개 색상 블록을 추출하고 관계없는 장식 색상은 사용하지 않습니다

화면 공간이 부족하면 인물 사실, 얼굴 식별도, 헤어스타일, 의상 일관성, 완전한 삼면도를 먼저 보존하고 표정과 분해 모듈의 정보 밀도를 줄입니다. 정면 얼굴 클로즈업이나 삼면도를 삭제하지 마세요.

## 출력 구조(세션 언어로 하나의 연결된 문장으로 작성)

```
가로형 캐릭터 설정 참조 시트. 왼쪽은 정면 얼굴 메인 초상, 중앙은 6가지 표정과 의상·소품 디테일 분해, 오른쪽은 정면·90도 측면·후면 같은 키 전신 뷰 3장을 나란히 배치하고, 하단은 캐릭터의 실제 외형에서 추출한 5색 팔레트 띠로 구성;
모든 모듈은 같은 캐릭터이며 세 전신 뷰는 전신이 화면에 들어오고 중립적인 A자 서기 자세, 같은 키로 머리 꼭대기와 발바닥을 정렬;
[나이대 + 성별감 + 체형], [이목구비 특징], [헤어스타일], [의상 + 액세서리 + 상징적 소품];
정면 얼굴, 6가지 표정, 의상·소품 분해, 세 전신 뷰의 얼굴·헤어스타일·의상·소품은 완전히 동일;
순백 배경, 부드럽고 고른 조명, 영화적 질감
```

## 묘사 순서 규칙

**가장 식별도가 높은 특징을 앞에 배치**하고, 템플릿 예시로 인물 사실을 바꾸지 않으며 `appearance`와 `styling`의 모든 핵심 요소를 다음 순서로 빠짐없이 구체화합니다.

1. 정체성 앵커: 나이대, 성별감, 체형(키, 체격, 평소 자세 습관)
2. 이목구비: 얼굴형, 눈, 코, 입, 기타 뚜렷한 특징(흉터, 점, 안경 등) — 정면 얼굴 클로즈업은 특히 이 묘사에 의존합니다
3. 헤어스타일: 색상, 길이, 스타일
4. 의상: 디자인, 색상, 소재, 상태, 정면과 후면에서 확인할 수 있는 구조적 세부
5. 액세서리와 소품: 인물 설명에 등장하는 식별 가능한 것만 쓰고, 과하게 쌓거나 새로 만들지 않습니다
6. 외적으로 보이는 분위기와 표정: 성격 특성을 눈빛, 표정, 서 있는 자세, 신체 상태처럼 보이는 묘사로 바꿉니다(예: "초췌함" → "피곤한 눈빛과 살짝 처진 어깨"). 추상적인 성격 단어를 나열하지 않습니다

원래 인물 설명을 최우선으로 합니다. 나이, 성별, 체형, 이목구비, 헤어스타일, 의상, 액세서리, 소품을 바꾸지 마세요. 설명에 없는 세부는 중립적이고 간결하게 유지하며 강한 식별성을 가진 설정을 임의로 추가하지 않습니다.

## 구도와 일관성

- 왼쪽 정면 얼굴 클로즈업: 카메라를 정면으로 향하고 중립적인 표정, 머리 꼭대기부터 어깨까지 완전히 화면에 들어옴
- 중앙 6가지 표정: 평온, 미소, 분노, 놀람, 슬픔, 집중. 얼굴 비율, 얼굴형, 헤어스타일, 의상은 유지하고 표정과 분위기만 바꿈
- 오른쪽 세 가지 전신 뷰: 같은 캐릭터의 정면, 90도 측면, 후면. **같은 키로 나란히, 간격을 고르게** 배치하고 머리 꼭대기와 발바닥을 같은 수평선에 정렬
- 클로즈업, 표정, 의상·소품 분해, 세 전신 뷰는 반드시 같은 얼굴, 같은 헤어스타일, 같은 의상, 같은 소품 구성을 가져야 합니다 — "모든 모듈의 얼굴·헤어스타일·의상·소품은 완전히 동일"하다고 명시합니다
- 삼면도는 중립적인 A자 서기 자세와 자연스러운 표정을 사용하고, 이후 이미지와 영상의 참조 앵커로 재사용하기 쉽게 만듭니다
- 의상과 소품 분해는 현재 캐릭터의 디자인만 설명하며 다른 의상, 추가 액세서리, 다른 인물을 만들지 않습니다
- 색상 팔레트 띠는 캐릭터의 실제 외형에서 추출한 정확히 5개의 조화로운 색상 블록으로 구성하며 임의의 장식 색상을 사용하지 않습니다
- 부드럽고 고른 스튜디오 조명을 사용하고 극적인 명암은 피합니다. 참조 시트는 여러 장면에서 사용할 수 있어야 합니다
- 출력은 세션 언어 지시가 지정한 목표 언어를 사용하고 관계없는 어휘를 섞지 않습니다

## 금지 사항

- 역동적인 포즈, 과장된 표정, 삼면도에서 손에 든 소품, 다른 사람과 함께 등장하거나 새로 추가한 인물
- 신체 잘림(전신 뷰는 머리 꼭대기부터 발바닥까지 완전히 보여야 하고 클로즈업은 머리와 어깨가 완전히 보여야 함)
- 지시 없이 인물 사실, 얼굴형, 헤어스타일, 의상, 소품 또는 팔레트의 출처를 변경하는 것
- 기본적으로 텍스트, 제목, 라벨, 숫자, 워터마크, 서명, 소셜 계정 표시를 넣지 않습니다. 사용자가 명시적으로 요청한 경우에만 레이아웃 텍스트를 생성합니다
- 플레이어 아이콘, 재생 버튼, 동영상 진행 막대, 자막 레이어, 불필요한 테두리, UI 요소
- 짙은 그림자, 컬러 배경광, 배경 소품, 무작위 장식, 캐릭터와 관계없는 색상 블록
