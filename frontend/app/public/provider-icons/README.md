# Provider icons

The 18 original SVGs in this directory are from [LobeHub Icons](https://github.com/lobehub/lobe-icons), pinned to `@lobehub/icons-static-svg@1.95.1`, copied from the approved provider design. Xiaomi MiMo API and Token Plan share one brand icon.

See [icon-sources.json](./icon-sources.json) for exact upstream URLs and [LICENSE-icons.txt](./LICENSE-icons.txt) for the MIT license. Brand trademarks remain with their respective owners; this is not an endorsement.

`dark/*.svg` are local adaptations of the five monochrome originals (currentColor replaced by a light foreground). `kimi-color-badge.svg` places the unmodified Kimi artwork on a padded dark plate so its white K is visible in both themes. Original SVG files are retained alongside these adaptations.
